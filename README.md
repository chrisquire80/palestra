# Palestra

App per registrare gli allenamenti di Christian nel foglio Google.

Apri l’app dal telefono usando il link nella scheda **App** del foglio. Da lì puoi aggiungerla alla schermata Home (su Android, in Chrome: Installa app).

Il foglio resta l’unica fonte dei dati. Non mettere il link di configurazione in un messaggio o in un file pubblico.
